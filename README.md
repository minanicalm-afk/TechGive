# Vifaa

Landing page for a computer sales and repair company in Juja and Nairobi: device donations, repair-and-give, paid disposal, fleet upgrades, and buyback.

## Develop

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Before you share it

In `lib/site.ts`, set `whatsappE164` to the company WhatsApp number (digits only, country code included) and update `whatsappDisplay`. The name Vifaa is a working title in that same file.
